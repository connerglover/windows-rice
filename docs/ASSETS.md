# Asset provenance

The primary garden wallpaper is [MrDLingters' colorized 85mqwy](https://github.com/MrDLingters/EverforestWin11/blob/88f430bd2d1d32a9ba3070f4531ece36c96e133c/Wallpapers/wallhaven-85mqwy-colorized.png). The second original colorized wallpaper is `wallhaven-xley1v-colorized.png` in that same repository.

The private collection also contains Wallhaven IDs [2y751g](https://wallhaven.cc/w/2y751g), [3koo73](https://wallhaven.cc/w/3koo73), [438epv](https://wallhaven.cc/w/438epv), [8o8qkk](https://wallhaven.cc/w/8o8qkk), [lqmd2l](https://wallhaven.cc/w/lqmd2l), [m9vmz1](https://wallhaven.cc/w/m9vmz1), [qzm89d](https://wallhaven.cc/w/qzm89d), and [qzx2kq](https://wallhaven.cc/w/qzx2kq). Consult each source for uploader/artist information and usage terms. None are claimed as project-owned artwork.

`assets/Icons` preserves the custom folder/Windows symbols and palette adaptations of installed app icons. Names in resource filenames identify the original module; resource IDs preserve the mapping. Hydra, Todoist, WezTerm, CAVA, DuckStation, PCSX2, PPSSPP and game adaptations are under `Expanded/NewApps`. Fluver and FluentFlyout artwork is prepared but not substituted into their packaged Start entries.

`assets/Cursors/Bibata-Everforest-Windows` is the sage adaptation of Bibata. `assets/Sounds` contains seven original synthesized cues: Dew, Rain, Fern, Falling Leaf, Amber, Ember and Bloom.
